## 🔬 Things people actually use

**[mcp-statcan](https://github.com/Aryan-Jhaveri/mcp-statcan)** ![stars](https://img.shields.io/github/stars/Aryan-Jhaveri/mcp-statcan?style=flat&label=★)
Lets Claude (or any MCP client) search and pull from 7,000+ Statistics Canada tables, plus a `statcan` CLI if you just want the data without an LLM. It's on PyPI, in the MCP registry, and there's a free hosted server so you don't have to install anything!
`Python` `MCP` `SDMX` `SQLite` `GitHub Actions`

**[dbRIP](https://github.com/Aryan-Jhaveri/dbRIP)** · [web app](https://aryan-jhaveri.github.io/dbRIP/)
Built for the Liang Lab at Brock. Their database has 44,984 transposable element insertions (ALU, LINE1, SVA, HERVK) across 33 populations, and I wrapped it in a REST API, a React app, a CLI, a UCSC Genome Browser track hub, and an MCP connector. The lab pushes one CSV and CI rebuilds everything.
`FastAPI` `React` `TypeScript` `UCSC track hubs` `Docker`

**[mcp-foodguidecanada](https://github.com/Aryan-Jhaveri/mcp-foodguidecanada)** ![stars](https://img.shields.io/github/stars/Aryan-Jhaveri/mcp-foodguidecanada?style=flat&label=★)
Canada's Food Guide recipes + the Canadian Nutrient File + Dietary Reference Intakes in one place, so you can ask "plan me a week of meals" and get real nutrition math back, not vibes.
`Python` `MCP` `Health Canada APIs`

## 🛠️ Things I built because I wanted them

**[Vastra](https://github.com/Aryan-Jhaveri/Vastra.cc)**
My smart wardrobe! Take a photo of your clothes and it tags them, suggests outfits for today's weather, and lets you try things on virtually. Self-hosted, installs as a PWA, multiple accounts, and has its own MCP server.
`TypeScript` `React` `Gemini` `Docker` `PWA`

**[MCGEE](https://github.com/Aryan-Jhaveri/MCGEE)** · [demo](https://www.youtube.com/watch?v=_hWtLnabNxg)
Five AI agents working together to turn a plain-English research question into Google Earth Engine code that's actually been checked against real dataset and band names.
`Python` `Multi-agent LLMs` `Next.js` `WebSockets`

**[GetEmmaToTasmania](https://github.com/Aryan-Jhaveri/GetEmmaToTasmania)**
A flight price tracker for Emma! Checks Toronto → Tasmania every morning, writes to a Google Sheet, and emails her when it's cheap. Emma never has to touch code!
`Python` `GitHub Actions` `Google Sheets API`
